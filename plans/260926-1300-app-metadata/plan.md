# Metadata: titles, icons, a link preview, a manifest

Every tab reads "SuperDB", there is no favicon at all, and a link pasted into chat previews as bare
text. With several projects open at once — the thing this app is for — the tabs cannot be told apart.

## Phase 1 — the whole of it (single phase)

| Status | Effort |
|---|---|
| in-progress | ~2h |

### Decisions

- **Titles name the project.** `Table Editor | superdb | SuperDB`. The project layout's
  `generateMetadata` sets the template from `resolveProject`, which is `cache()`d, so the name costs
  no second fan-out. `title.absolute` for the layout's own title, so the root's template cannot
  wrap it a second time.
- **The mark is the one already on screen**: Tabler's database icon in `#3ecf8e` on `#121212`, as
  the sidebar and the sign-in card draw it. One drawing, shared by every generated image.
- **Everything is generated by `next/og`**, already part of Next — no new dependency, no binaries in
  the repo. Icons at 32, 192 and 512 through `generateImageMetadata`, `apple-icon` at 180, the
  preview at 1200×630. All static at build.
- **A manifest**, with the 192 and 512 icons, dark theme colour, `display: standalone`.
- **`robots` stays `noindex`.** This is a signed-in dashboard; link previews ignore `noindex`.
- `metadataBase` is `https://database.drisdev.io`, where it is deployed.

### The trap: the proxy would hide all of it

`proxy.ts` sends every path it matches to `/login` when signed out, and its matcher only skips
paths **ending** in `.svg|.png|.jpg|.webp`. Generated metadata routes have no extension —
`/icon/32`, `/apple-icon`, `/opengraph-image` — and the manifest ends in `.webmanifest`. A link
preview bot is signed out, and a browser fetches the manifest without credentials, so without a
matcher change every one of these answers a redirect to the sign-in page. They are public images and
a public manifest; excluding them exposes nothing.

### Related code files

- Modify: `app/layout.tsx` — template, description, `metadataBase`, `openGraph`, `twitter`,
  `applicationName`, `viewport`
- Modify: `app/(app)/p/[ref]/layout.tsx` — `generateMetadata` with the project name
- Modify: every `page.tsx` (26) — its title
- Create: `components/brand-mark.tsx` — the shared drawing
- Create: `app/icon.tsx`, `app/apple-icon.tsx`, `app/opengraph-image.tsx`, `app/manifest.ts`
- Modify: `proxy.ts` — the matcher

### Success criteria

- [ ] A project page's title carries page and project; pages outside a project carry the page.
- [x] The built `<head>` has icon links, apple-touch-icon, manifest, `og:image` and `twitter:card`.
- [x] Signed out, `/icon/32`, `/apple-icon`, `/opengraph-image` and `/manifest.webmanifest` answer
      200 with an image or JSON — not a redirect.
- [x] `pnpm typecheck`, `lint`, `test`, `build` green.

### Risks

- **A matcher that excludes too much** lets a signed-out request reach a page. The exclusions are
  exact route names, and `/api` and the app routes are untouched.
